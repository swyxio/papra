# Files controls

The chosen ImageGen directions were D's utilities below pagination and C's Ask panel. The design keeps a compact search row, uses object menus for file and folder actions, and leaves the file list visible beside Ask on wide screens. The original concept sheet and Chrome captures are in the design conversation.

- New / Import contains uploads, Google Docs import, and Create from template. Sponsorship Order is an existing choice in the template catalog.
- Filters and Sort sit beside search. Applied person and property filters appear as removable chips. Column sorting stays available.
- The current folder menu contains Move files here, Rename, Move folder to, Folder access, and Delete folder where permitted. File and subfolder rows have visible menus and right-click actions.
- Ask this space and Export space sit below pagination. Space settings contains Automation access, with folder-scoped tokens for scripts and integrations.

The [Fluent toolbar guidance](https://fluent2.microsoft.design/components/web/react/core/toolbar/usage/) informed visible actions and labeled overflow. [Finder list view](https://support.apple.com/en-euro/guide/mac-help/mchldaafb302/mac) informed column sorting and [Drive search](https://support.google.com/drive/answer/2375114) informed filter chips.

Chrome captures used a signed-in local fixture with a subfolder, two files, and a custom property. At 1413 pixels wide, the Ask panel sits beside the list and both Ask actions fit on one row. At 390 pixels wide, the breadcrumbs sit above the folder controls and the Ask panel stacks below the utility bar without horizontal overflow. The fixture returned a sample answer and source to verify rendering and state when reopening the panel.
